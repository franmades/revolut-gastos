Política de privacidad

Aplicación: Revolut Gastos

Esta aplicación es una herramienta personal destinada exclusivamente al titular de la cuenta para consultar y analizar sus propias transacciones de Revolut.

Datos tratados

La aplicación puede acceder, con autorización del titular, a información de cuentas y transacciones necesaria para calcular el gasto realizado mediante tarjeta.

Finalidad

Los datos se utilizan únicamente para el control personal de gastos. No se venden, alquilan ni utilizan para publicidad.

Conservación y seguridad

Los datos se conservarán únicamente durante el tiempo necesario para esta finalidad y se adoptarán medidas razonables para protegerlos frente a accesos no autorizados.

Compartición

No se compartirán los datos con terceros, salvo cuando sea necesario para prestar el servicio de conexión bancaria autorizado por el titular o cuando exista una obligación legal.

Contacto

Para cualquier cuestión relativa a privacidad, puede utilizarse el mismo correo electrónico empleado para registrar la aplicación.
